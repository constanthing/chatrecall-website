Pinning now reaches your Claude Code and Cowork sessions.

## Added

- Two-way pinning for Claude Code and Cowork cloud sessions. A session pinned on claude.ai shows as pinned in your library after a sync, and the Reader's pin button pins or unpins the session at claude.ai itself, through the same synced store the claude.ai sidebar reads. Pins made anywhere follow your account, not the browser they were made in.
- Pins on local sessions are captured too. A Claude Code or Cowork session pinned in the Claude desktop app on this computer arrives in your library as pinned on the next sync.
- Zoom appears in the sync source list. Connecting a Zoom account is not possible yet, so selecting the source finds nothing until that lands.

## Improved

- The Reader's pin button now explains itself on sessions whose pin the app cannot change, instead of attempting a push that cannot succeed: sessions that live on this computer point you to the Claude desktop app.
