A Files page that gathers every attachment across your chats in one
place, and a simpler, more informative sidebar.

## Added

- A Files page, sitting between Projects and Usage in the sidebar. It
  lists every file across your whole archive: the ones you attached to
  prompts and the ones the chats produced in their replies, newest
  conversation first, each row showing where the file came from. A search
  box covers file names and conversation titles, and one filter chip per
  file type (with counts) makes "show me every PDF" a single click. The
  sidebar's source rows narrow the list in place, exactly as they do for
  your chats, and newly captured files appear while a sync runs without
  leaving the page.
- Every file offers two ways to open it: inside ChatsRecall, with the
  conversation opened right at the message that carries the file, or on
  the original chat page in a connected browser, scrolled to that message
  and highlighted. ChatsRecall stores file names and types, never the
  file contents, so opening a file always means finding it where it
  lives.

## Improved

- The Sync row in the sidebar now shows when the last sync finished
  ("5m ago") right on the row, replacing the small status line that used
  to sit at the bottom of the sidebar. While a sync runs, the familiar
  activity ring takes its place.
- Help is now a labeled row in the sidebar footer instead of a bare icon,
  and the Help dialog is more focused: open the Help page or replay
  onboarding from the beginning. The extension setup guide on its own is
  still available from Settings.
- The dark mode switch moved to Settings, under a new Appearance section,
  instead of a small icon at the bottom of the sidebar. The choice still
  applies everywhere and is remembered between launches.
