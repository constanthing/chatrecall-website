Rename a conversation in ChatsRecall and the source follows.

## Added

- Two-way renaming. The Reader's header has a rename action: click the pencil,
  type the new title, press Enter, and the conversation is renamed at its
  source. The title in your library only changes once the source confirms.
  Works for ChatGPT, Claude, Gemini, Grok, Perplexity, Copilot, Wave, and
  Claude Code and Cowork cloud sessions. Where a source has no rename (Google
  AI Mode, meeting notetakers, imports, local Claude sessions), the action
  stays visible but disabled, with a tooltip saying why.
- Open at source from any message. Every prompt and response in the Reader
  has an action that opens the original conversation in your browser scrolled
  to that exact message, with the message outlined on the page.

## Fixed

- Wave favourites. Wave moved its favourite toggle into a "Session tools"
  dialog, which left favourite status stuck at "not favourited" for captured
  sessions and broke pinning from the app. Both follow the dialog now.
