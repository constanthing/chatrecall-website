Make search more precise and Claude Cowork conversations more complete and reliable.

## Added

- Claude Cowork web conversations now include uploaded files and files delivered by Cowork.

## Improved

- Search now matches whole words or the start of a word, so short queries no longer match letters buried inside unrelated words. Highlighting follows the same rule, and result excerpts now center on the actual match.
- Conversation timestamps older than four weeks now show a calendar date instead of an increasingly large number of weeks.
- Claude Cowork conversations now update automatically when work finishes, including when returning to an already-open Chrome tab.
- Existing Claude Cowork web conversations are refreshed once to add available attachment information.
- Cowork transcripts now exclude internal skill instructions, system reminders, and tool-processing events.
- Claude Code and Cowork conversations now show cleaner repository and branch information.

## Removed

- Internal Claude Cowork warning-placeholder conversations are removed from the library and search results.
