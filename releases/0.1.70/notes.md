A calmer, more consistent look across the app in both themes, and Claude Code's on-disk sessions now sync as their own lane.

## Added

- Claude Code and Claude Cowork conversations stored on this computer now sync as their own "This computer" lane beside the browser lanes, with its own badge on the Sync page, its own rows in the live view and Sync History, and its own counts. Session files are read directly from disk, no browser window needed.
- Sync page sources are now compact badges with a status dot. Hovering shows the stored conversation count and last synced time; right-clicking a source with stored data offers to remove its local copy.

## Improved

- A visual refresh across every page in both themes: flat surfaces with hairline borders replace gradients, glows, and blur; a single refined accent covers the primary action, active navigation, focus, and links; typography is calmer; status colors are softer tints. Light mode now sits on a near-white background with white cards. The website matches.
- Source names on cards, list rows, and the Files page read in quiet text while the colored source mark carries identity, keeping busy pages readable.
- While a sync runs, every row in the live view leads with the source's own tinted glyph, so a glance shows which source is being worked on.
