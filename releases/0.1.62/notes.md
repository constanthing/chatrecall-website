Opening ChatsRecall while it is already running now brings back the window you already have instead of starting a second copy.

## Fixed

- Launching ChatsRecall from the Start menu while it was already running used to start a second copy of the app, with its own tray icon. The copies then competed for the browser connection and the conversation archive, which could quietly break live capture and make syncs fail. A second launch now simply brings the existing window to the front.

## Improved

- Opening ChatsRecall while it is hidden in the system tray now reopens its window right away, the same as clicking the tray icon.
