Connect every supported browser, jump straight to the search result you need, and keep your library accurate across accounts.

## Added

- Connect multiple Chrome and Microsoft Edge extensions at the same time, with account-safe syncing and browser-specific routing.
- Use the new Extensions page to see every connected extension and copy the extension link for installation in another browser.
- Open a matching prompt or message from search results either inside ChatsRecall or at its exact highlighted location in the source browser.

> **Compatibility note:** Multiple extensions can connect and operate now, but ChatsRecall cannot identify a browser until that browser's extension is updated. Older extensions appear as unidentified legacy connectors.

## Improved

- Library search results are ordered newest-first, with relevance used as a secondary ranking factor.

## Fixed

- Internal Claude Cowork `*warming*` conversations are now cleaned up correctly; the previous implementation mistakenly targeted `*warning*` titles.
