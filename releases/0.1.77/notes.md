Create your own projects that mix conversations from any source, and search options now live in one place.

## Added

- ChatsRecall projects: create a project inside the app and fill it with
  conversations from any mix of sources. Right-click a conversation card to
  add or move it, or use the folder button while reading a conversation.
  Projects live only in ChatsRecall: syncing never touches them, and deleting
  one never deletes any conversations.
- Claude Code sessions now group into folders by the repository they worked
  in, covering both cloud and local sessions.
- A short one-time walkthrough after this update points out where the search
  filters moved and how to create your first project.

## Improved

- The search field is now the single place for finding things. A sliders icon
  inside it opens the search options: the choice between Classic and Ladder
  search, Ladder's result sorting, and the file-type filter. A small dot on
  the icon shows when any of these is set away from the default. The sparkles
  button in the same field opens Ask your archive.
- Starting a new chat moved from the header button to a dashed card ahead of
  the first conversation.
- Conversation cards show a folder chip naming the project or folder they
  belong to.
- While a search is still running, a "Searching" indicator shows instead of
  claiming there are no results.
- The filter button next to SOURCES shows a dot while any source is hidden,
  and the sidebar's conversation counts always match the conversations shown.
