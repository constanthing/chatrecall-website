Source visibility now lives in one place, and the update window catches you up on releases you skipped.

## Added

- Sources popover: the filter button next to the SOURCES label now manages
  everything about source visibility in one place. Each source can be Shown,
  kept out of the sidebar only, or hidden from the library and search
  entirely, and you can drag sources into your own sidebar order. Hiding is
  display only: every source keeps syncing and its data stays put.

## Improved

- The update window now catches you up. If you skipped versions, it also
  shows the release notes for every update between your version and the new
  one, each under its own heading.
- The per-source library switches moved from Settings into the sources
  popover, so visibility lives in one place.
